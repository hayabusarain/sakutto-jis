# データの出どころと確認状況

2026年10月1日時点。サイトに載せている規格の数値について、どこから取り、どう確かめたかをまとめています。

## 前提（作成時の制約）

作成した環境（Claude Code のクラウド環境）では、ネットワーク設定により規格原文のサイト（kikakurui.com・JSA・JISC）やメーカーサイトにアクセスできませんでした。また、作成に使った AI の Web 検索機能には1回の作業で使える回数の上限があり、調査の途中で上限に達しました。どちらも作成時の環境の制限で、公開後のサイトの動作には影響しません。そのため、数値は次の3つを組み合わせて確かめました。

1. 公開されている二次データ（GitHub 上の規格表の転記、CADソフトのデータ、旧規格の英語版など）
2. 規格の計算式による整合チェック（テストに組み込み済み）
3. 作成者の知識との突き合わせ

**公開前に、下の「要確認」の項目を規格原文で確認してください。** 規格原文は [JISC の JIS 検索](https://www.jisc.go.jp/) で閲覧できます。

確度の目安

- ◎: 独立した2つ以上のソースで一致、または規格の式・表で再現できる
- ○: 1つのソース＋整合チェック、または部分的な照合
- △: 作成者の知識が主な根拠（公開前の確認を推奨）

## 画面上の「※」印

フランジとボルト寸法のツールでは、上の表で △ や「要確認」にした値に、画面・コピー文・CSV で「※ 規格原文で未確認の値」の印を付けています。印を付ける値は、各ツールの `data.ts` にある `UNVERIFIED` で管理しています。原文で確認できたら、この文書と `UNVERIFIED` の両方を更新してください。

寸法表のページ（`/flange-bolt-length/16k` など）とねじのまとめページ（`/screw/m12` など）、クイック検索（`src/lib/quickSearch.ts`）でも、同じ値に ※ を付けています。どこも、判定には各ツールの `UNVERIFIED`（`isUnverified()`・`isRowUnverified()`）をそのまま使っています。

- 厚さ t が未確認の行（16K の全サイズ、5K 50A）では、その厚さから計算したボルト長さにも ※ を付けます（寸法表の CSV の「確認状況」も「要確認（厚さ・ボルト長さ）」）
- ねじのまとめページの「このボルトを使うJISフランジ」では、行ごと未確認の呼び径（5K・10K の 90A・175A・225A）に ※ を付けます。厚さだけが未確認の行には付けません（ボルトの径と本数しか載せていないため）
- クイック検索では、フランジの値・ボルト寸法のざぐり径 D'・M3 の旧JIS 二面幅に ※ と凡例を付け、G めねじの推奨下穴径は「計算値」と表示します
- 普通公差のページは値がすべて △ のため、個々の値ではなく、ページ・コピー文・CSV に「JIS B 0405 原文とは照合中」の注記を付けています読者向けには、この文書の要点を「編集方針・データの確認方法」のページ（`/editorial-policy`）にまとめています。

## サイト独自の目安（規格の値ではないもの）

次のものは、画面やガイドで「サイト独自の目安」「参考」と明記しています。

| 場所 | 内容 |
| --- | --- |
| ねじの判別 | 候補の並べ方（径の差 0.1mm＋基準径の1%、ピッチの差 2% を許容とする点数）、テーパ判定のしきい値、インチねじの注意を出す基準（いちばん近い候補が「よく合う」でないとき、または「よく合う」でもピッチの差が 3% を超えるとき。`PITCH_CAUTION_PERCENT`） |
| 鋼管の実測から探す | 外径が「近い」とする範囲（1mm または外径の3%）、厚さで規格を見分ける目安 |
| Oリングの実物寸法から探す | 太さが P・G のどれからも離れているとする目安（8%） |
