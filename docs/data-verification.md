# データの出どころと確認状況

2026年9月30日時点。サイトに載せている規格の数値について、どこから取り、どう確かめたかをまとめています。

## 前提（作成時の制約）

作成した環境（Claude Code のクラウド環境）では、ネットワーク設定により規格原文のサイト（kikakurui.com・JSA・JISC）やメーカーサイトにアクセスできませんでした。また、作成に使った AI の Web 検索機能には1回の作業で使える回数の上限があり、調査の途中で上限に達しました。どちらも作成時の環境の制限で、公開後のサイトの動作には影響しません。そのため、数値は次の3つを組み合わせて確かめました。

1. 公開されている二次データ（GitHub 上の規格表の転記、CADソフトのデータ、旧規格の英語版など）
2. 規格の計算式による整合チェック（テストに組み込み済み）
3. 作成者の知識との突き合わせ

**公開前に、下の「要確認」の項目を規格原文で確認してください。** 規格原文は [JISC の JIS 検索](https://www.jisc.go.jp/) で閲覧できます。

確度の目安

- ◎: 独立した2つ以上のソースで一致、または規格の式・表で再現できる
- ○: 1つのソース＋整合チェック、または部分的な照合
- △: 作成者の知識が主な根拠（公開前の確認を推奨）

## 画面上の「※」印

フランジとボルト寸法のツールでは、上の表で △ や「要確認」にした値に、画面・コピー文・CSV で「※ 規格原文で未確認の値」の印を付けています。印を付ける値は、各ツールの `data.ts` にある `UNVERIFIED` で管理しています。原文で確認できたら、この文書と `UNVERIFIED` の両方を更新してください。

## サイト独自の目安（規格の値ではないもの）

次のものは、画面やガイドで「サイト独自の目安」「参考」と明記しています。

| 場所 | 内容 |
| --- | --- |
| ねじの判別 | 候補の並べ方（径の差 0.1mm＋基準径の1%、ピッチの差 2% を許容とする点数）、テーパ判定のしきい値 |
| 鋼管の実測から探す | 外径が「近い」とする範囲（1mm または外径の3%）、厚さで規格を見分ける目安 |
| Oリングの実物寸法から探す | 太さが JIS のどれからも離れているとする目安（8%） |
| 図面指示の例（下穴・ボルト穴・座ぐり・管用ねじ・Oリング溝） | 書き方の一例。記号（⌴・↧）や「キリ」「深ザグリ」の表記は JIS B 0001 原文と未照合 |
