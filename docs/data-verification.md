# データの出どころと確認状況

2026年10月3日時点。サイトに載せている規格の数値について、どこから取り、どう確かめたかをまとめています。

## 確かめ方

2026年10月に、各ツールの JIS の数値を、JIS の規格票の原文とすべて照合しました。

1. **規格票の原文との照合**: JIS 規格票の画像（kikakurui.com で公開されているもの）を拡大して表を読み取り、サイトの `data.ts` の値と、`calc.ts` で計算した値（基準寸法・許容範囲・単位質量など）を1つずつ突き合わせました。読み取りは、別の担当がもう一度独立に読み直して照合し、すべての判定が一致しました（作業は生成AI（Claude）で行い、読み取った値と比べた結果は作業用の記録に残しています）。
2. **規格の計算式による整合チェック**: 単位質量・つぶし率・ねじの基準寸法などを、規格の式で計算し直して表の値と比べるテストを `*.test.ts` に組み込んでいます（`npm test`）。
3. **年版の確認**: 2026年10月3日に、日本規格協会（JSA）の Webdesk で各規格の現行の年版を確かめました（下の「規格の年版」）。

サイトの画面では、典拠として JIS の規格番号・年版・表番号（例: 「JIS B 2220:2012 表15 呼び圧力10Kフランジの寸法」）を示します（`Citation` の `detail`、クイック検索のカードは `SummarySection.details`）。読み取りに使った kikakurui.com は画面の典拠には書きません。規格原文は [JISC の JIS 検索](https://www.jisc.go.jp/) で閲覧できます。

確度の目安

- ◎ 原文と一致: JIS 規格票の原文の表と照合して一致した
- ◎ 計算: 規格の式で計算した値（規格に表がある範囲では、表の値とも一致）
- ○: 二次資料との照合や整合チェックで確かめた（原文とは未照合）
- △: 主な根拠が作成者の知識で、規格原文で確認していない（画面で ※ を付ける）
- 計算値・参考値・目安: 規格の値ではない（画面にそう書く）

**規格票の印刷の誤り**: JIS B 2401-2:2012 表3 の P48A〜P60 の欄（印刷8ページ）は、溝幅 b3（バックアップリング2個）が「1.5」と印刷されています。同じグループの続き（P62〜P150）と、太さが同じ G150〜G300 は 11.5 で、b3 は b2（9.0）より大きいはずなので、印刷の誤りとみて 11.5 を載せています。正誤票（2013年）には載っていません。P48A〜P60 で円筒面・バックアップリング2個を選んだときの画面、P の寸法表、P の CSV にこの注記を出します（`B3_MISPRINT`）。

収録しているのは P・G 系列だけです。真空フランジ用の V 系列（JIS B 2401-1 表7・JIS B 2401-2 表5）は規格にあり読めますが、このサイトでは扱っていません。

## 画面上の「※」印

規格原文で確認できていない値には、画面・コピー文・CSV・寸法表・ねじのまとめページ・クイック検索で「※ 規格原文で未確認の値」の印と凡例を付けます。印を付ける値は、`src/features/flange-bolt/data.ts` と `src/features/bolt-size/data.ts` の `UNVERIFIED` で管理しています。

**いまは両方とも空で、※ を付けている値はありません。** 2026年10月の照合で、それまで ※ を付けていた値（フランジの 16K の厚さ・5K 50A の厚さ・5K と 10K の 90A・175A・225A の行、ボルト穴径 4級・ざぐり径 D'、附属書JA の M3 の二面幅）はすべて原文と一致したため外しました。

仕組み（`isUnverified()`・`isRowUnverified()`、凡例、寸法表の CSV の「確認状況」の列）は、今後原文で確認できていない値を載せるときのために残しています。`UNVERIFIED` に足せば、各ページに ※ と凡例が出ます。仕組みのテストは仮の一覧を使っています（`flange-bolt/calc.test.ts`・`bolt-size/data.test.ts`・`pages/tables/tableData.test.ts`・`lib/quickSearch.unverified.test.ts`）。管用ねじの Rc の有効ねじ部の長さが `null` のサイズも「未確認」と表示する仕組みが残っていますが、いまは該当がありません。

読者向けには、この文書の要点を「編集方針・データの確認方法」のページ（`/editorial-policy`）にまとめています。
